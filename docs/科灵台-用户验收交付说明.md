## 一、科灵台是什么，现在能不能用

科灵台是长在 DeepSeek Harness（DSH）里的一个科研插件，核心是一个叫**科灵**的智能助手。它想做的事很单纯：陪你把「一个模糊的科研灵感」一步步变成「能分享出去的成果」——查资料、读全文、问问题、找选题、写草稿、做验证、导出成稿，科灵全程搭把手。

**现在的真实状态：开发中的实验性工具，尚未定型。** 核心链路（检索 → 精读 → 问答 → 选题 → 草稿）已经能跑通，但不少环节还在打磨。我们**如实建议**：可以尝鲜、可以反馈，但先别拿它跑正式科研流程。

一句话记住：**代码层面全绿，但真机验收还没完成——这两件事不能划等号。**

## 二、你现在能做什么（照着用就行）

| 你想做的事 | 怎么找到它 | 现在到什么程度 |
| --- | --- | --- |
| 记一条灵感 / 贴个链接 | 首屏输入框直接记 | 可用 |
| 查文献、建文献库 | 「资料」页签，检索 arXiv / Europe PMC / OpenAlex 三个免费来源 | 可用，暂未接中文库 |
| 让科灵读全文、带引文问答 | 选中文献后提问 | 可用 |
| 找选题、写综述、起草稿 | 「选题 / 成稿」相关页签 | 可用，逐步完善中 |
| 让科灵带队验证（虚拟实验室） | 输入框旁「靶心」按钮「交给科灵 · 到虚空验证」 | 可用；装包、改工作区仍需你在决策区拍板 |
| 让科灵看图回答（识图） | 输入框「识图」选图，限 8 张 / 单张 ≤10MB | 可用；需先在科灵设置里切到支持图片的模型 |

界面是五个页签，首屏第一眼就能看到主行动入口。你可以直接开一个 DSH 客户端里的科灵台侧栏自己走一遍。

## 四、你要知道的边界（如实说，不制造虚假安全感）

- 三档权限只管科灵调用工具，管不到实验里跑的子程序；「离线」只拦代理层的外网请求，不等于机器断网。
- 「完全权限」不是免审批：装包、发包、改工作区这三类高风险动作，一律按 DSH 的 never 语义拒绝自动审批，必须你在决策区拍板。
- 目前没有静态代码扫描，实验代码只受运行总开关和路径白名单约束，更细的沙箱还在实现中——别说「没扫出问题就安全」。
- 数据只存在你本机的 `.dsh/research-desk/state.json`，没有云端账号，不上传。
