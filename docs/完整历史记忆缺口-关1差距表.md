## 决定性事实（逐字取证）
- 存储真相源：`chats[].messages` 是单一真相源，`state.chat` 只是活跃会话兼容镜像（lib/desk.mjs:432 注释）。
- 破坏链：对话写回时 `draft.chat = (...).concat([...]).slice(-200)`（lib/host.mjs:1384 chatQuestion / :1444 ask / :2528 chatStream / :2682 collabStream）。
- 覆盖：`syncActiveChat` 用 `state.chat` 全量覆盖 `row.messages`（lib/desk.mjs:417 `row.messages = (state.chat||[]).map(normalizeChatRow)`）。
- 后果：会话超过 200 条时，第 201 条起的早期问答被 `slice(-200)` 截掉后，经 syncActiveChat 永久抹除单一真相源——不是召回不到，是真实数据丢失。
- 召回：`chat_search`（lib/host.mjs:1915-1945）基 `chats[].messages` 全量做大小写不敏感子串匹配，但因真相源已被抹除，第201条前内容搜不到。
- 注入：`memoryBlock`（lib/host.mjs:857-948）画像+相似召回+最近8条+handoff 早期要点，每轮受窗口约束只注入相关上下文——此层合理，不动。
- 视图：`libraryView`（lib/host.mjs:709 `chat: state.chat.slice(-50)`）只控制前端返回量，非存储层，不动。

## 裁决：完整记忆的工程定义
- 记得 = 存储层全量不丢失（chats[].messages 保留每一条）。
- 完整 = 召回层任意可取回（chat_search 覆盖全量）。
- 使用 = 注入层智能压缩（每轮只注入相关，非全量背诵）。
