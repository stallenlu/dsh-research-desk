### 7.1 两条作废结论（书面确认）

1. **"测试环境代表用户真实环境、工具缺失走 UNAVAILABLE 是预期降级"——作废。** 本测试用独立临时 `DSH_HOME` + `web` profile，该 profile 未装 `dsh-scihub`/订阅生图来源包；而用户日常 `desktop` profile **确实装了** `dsh-scihub`（`C:/Users/GT14/.dsh/profiles/desktop/node_modules/dsh-scihub`，工具 `scihub_pdf`/`scihub_batch`，其 schema `doi`/`url`:string、`dois`:array 已核实，与科灵 `lib/host.mjs:65` `SCIHUB_NAMES` 及验真 `:74-83` 匹配）。所以本记录中一切 UNAVAILABLE 只能说明"这个隔离 web 实例里没找到工具"，**不能推断用户真实环境下工具真缺失，更不能当成预期行为**。用户质疑"装了却用不了"是必须查真因修复的问题，不是可搪塞的降级。
2. **"`test/toolBorrow.test.mjs` 11 条单测 + 476/476 回归覆盖'工具可用时借用链正确性'、全绿可信"——作废（假绿）。** 这套单测的 `makeTools`（`test/toolBorrow.test.mjs:14-25`）是手工 fake：`selectExecutor:()=>({describe...})`、`executable:name=>...`、`execute:async payload=>...`，**没有 scope / agent 概念**。而真实宿主 tools 服务是 scope-aware（据 KeLinTai 从 `D:/opt/DeepSeek Harness/resources/app.asar` 提取的 `ToolsService` 权威源码：`selectExecutor(scope)` 不传时 `scopeChainOf(undefined)` 为空链、`record` 回落 `this.root`，只要 root 有 executor 就**不抛**——旧推断"不传必抛 `ToolExecutorUnavailableError`"已由 Chief 纠正；真嫌疑在 `executable(name,scope?,toolSet?)` 无 scope 时 `view(undefined)` 大概率只覆盖 global 层）；宿主 per-agent scope 由 `this.scoped.set(scope,record)` 维护。科灵 `lib/toolBorrow.mjs:27-37` 全程无参（`ctx.get('tools')` → `selectExecutor()` → `executable(name)`）且 `try{}catch(e){}` 空吞——这些 UNAVAILABLE 的真实成因与 scope 范围不匹配有关，最终定论以 Chief/后端真机探针为准，测试侧不下结论。fake tools 永远返回工具，故单测全绿，**对真实 scope-aware 场景零覆盖**。476/476 只证明 helper 抽取未回归既有测试，不证明真实生态工具能被借到。

### 7.2 端到端到底验证了什么、没验证什么

- **验证了**：真实 DSH 宿主 + 真实 bundle + 前端同一条 HTTP 路由 `/api/research-desk/` POST `{action}` 可用；从该入口触发的 `status`/`search`/`add`/`library`/`read` 能拿到服务端真实人话回执；抓全文的 **search→add→read 入库链**真实走通（164 段入本地库、`message` 是算好的人话未暴露裸数据）；生图/scihub 在**未装工具的隔离 web 副本**中如实回 UNAVAILABLE、未伪造成功。
- **没验证**：三条借用能力（生图 / scihub 下载 / web_fetch 抓全文）的**生态工具调用本身**——端到端一条链都没走到（抓全文本例 `kind='html'` 走 arxiv HTML 直取旁路、`diag=[]`，未进 `lib/search.mjs:377-393` webFetchTool 借用链；生图/scihub 在 web 副本无工具）；用户真实 desktop 环境下这些工具**到底能不能被科灵借到**——desktop 实例受 Electron 独占 + bootstrap 不认临时 profile 双重环境阻断，两次尝试均未起成，未验证；工具可用时的 approved 闸门、下载回执字段等真实行为，单测假绿不算覆盖。
