## 摘要（执行结论）

本次审查围绕第一性原理与核心哲学，对科灵台从方案落地（1418371）到当前（65676fc）共 15 个提交做全维度只读取证，覆盖哲学落地、能力归属、交互信息架构、技术债可靠性、验收证据、迭代轨迹六个维度，并并入 DSH 原生设置 UI 的 asar 字节取证。

总判断：科研核心自建、通用能力按需借生态这两条主干守住了；四条能力边界逐字上屏、引文核验、证据链、靶心拍板、成稿三步、无假控件、无通用工具面板都已真实落地，不是纸面。但开发确实走过一段错误道路，且错误有共同结构——不是某个按钮做错，而是「决策未冻结、测试反写契约、宣称能力未在真实数据落地」三件事叠加，靠改 README 文案和改测试吸收变更，形成「自证闭环」的错觉。用户要求的「不盲目点状修复」正是要针对这三层根因，而不是再改一个入口。

审查不产生代码改动。本报告给出根因、优先级与可操作门禁，作为下一阶段工作的冻结基准。

## 二、权威基准（冻结用）

第一性原理（m21695 逐字）：科灵台是科研灵感工作台，帮研究者高效地把人类稀缺可行的灵感（若可，科灵辅助灵感产生）转化成可以分享的成果——这个不变。凡是有利于此定位的皆可考虑。LLM+Harness=Agent 是手段非定位。
五词组（v3→v4 定稿）：融合 · 各取所长 · 高效协调 · 通力合作 · 共同成长。
0.1 借生态（m21767/m21778）：科研核心（证据链、引文核验、靶心协作、成稿三步、拍板、能力边界上屏）自己做；通用能力（生图、网页抓取、运行时、导出）优先借 DSH 已装插件与开源成熟能力，场景化按需调用，不自己重造、不建罗列全场工具的通用面板。
用户反复强调：必要、简单、简洁、高效；优先借成熟做法，不自创复杂重复低效；一般用户第一眼能否看懂是 UI 标准。
章程门禁：哲学根仅 1.1/1.2/1.3，1.4/1.7 非根；每个按钮上线前必须指到真实 action/数据源（系统分析文档:115）；严禁自建 headless 当完成证据，test 仅回归护栏（:167）。

## 四、系统性偏差：三层根因（跨维度聚类，而非点状罗列）

### 根因一：决策未冻结，README 文案充当事实规格
证据：设置信息架构 11-21 当天四改——2d653fd「同一套设置面板…模型/权限/生图/思考强度」→68ac270「两个入口只是呈现方式不同」→cab7c0b「齿轮是完整设置的唯一入口…全在里面」→65676fc「齿轮是环境级设置唯一入口…只放生图配置与其他」（README.md:129，能力表:211 同步往返）；每次 code 改完文案跟着改，没有上游冻结决策。核心定位与五词组在 lib/client.js/lib/host.mjs 完全 0 表述，仅 README.md:3/:24 与零星文档残留（哲学 P2）。65676fc 瘦身后 D1 制造「gear 弹窗 dock 收起时不可达 model/perm/effort」且 README:129 留下自相矛盾的失信文案（IA D1）。
机制：没有冻结的设计基准，界面组织靠当次用户投诉驱动，README 的「唯一入口/分工」表述被反复重写当成规格。这正是系统分析文档:52「系统分析不再零散迭代」的反面，也是「不断在错误道路开发」的主因。

### 根因二：测试反写契约，形成「已验证」错觉
证据：client-ui.test.mjs 全文 263-264 处 src.includes 源码字符串断言、1145 行，属「读源码字符串」方法论，能检文案/结构存在，不能证明运行时行为（技术债 P1、迭代 D2）。最严重两处 P0：:583-586 用 lib/client.js:737 一行注释充当「协作已接入」证据，删注释假失败/留注释假通过；acceptance.mjs:80-83 把 skip 记 ok:true、:435-443 --skip-model 或无路由时把 C1-C4 记为通过、:556-559 汇总把跳过算通过。迭代审查证实每次前提翻转时测试只是被重写去匹配新前提（cab7c0b +28 行、2d653fd +51 行、65676fc +40 行）。index 切片未判 -1 的放松断言族（:268 等 20+ 处）marker 缺失可假通过。
机制：测试不是验证「真实 action/数据源存在」（系统分析:115），而是把当前实现甚至注释反写为契约；配合跳过记通过，形成「全绿=完成」的自证闭环，掩盖环境失败与能力未落地。与用户反复批评的「规格数、封印全绿等自证闭环」完全一致。

### 根因三：宣称能力与真实数据/在场工具之间有缝
证据：真实 state.json（C:/Users/GT14/.dsh/research-desk/state.json）fulltextKind 全为 abstract、web 零命中——「抓落地页全文」只在单测 mock 成立，真实数据未落地（证据 D2）；端口 12549 ECONNREFUSED 且 lib/host.mjs 不存在该端口常量（证据 D1，不虚构常量）；fbd7d7d 曾把「宿主已有 dsh-cite 可对接」写进能力表后被证伪（迭代 D3）；host.mjs:1002-1003 拍板注释为全局语气，实际仅 collabId 路径生效、实验台直跑不经装包/工作区闸门（哲学 P1，UI 已如实说明但不注释未同步）。
机制：「借生态 X」「端到端验收」「全局闸门」等表述先在文档/注释成立，再靠代码实现追赶；缺一次「在场探针 + 真实数据落地 + 失败回落」的验真闭环（能力验真门禁此前缺席）。
